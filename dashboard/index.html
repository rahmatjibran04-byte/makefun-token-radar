How the implied value is computed

Read this before farming

  • Every protocol on the pre-token board records no token in the snapshot — that is what the data says, not proof it has none. A protocol may still have a token its record does not carry.
  • The implied value is this entry’s own claim about what a token would be worth if the protocol’s record stayed as it is. It does not predict whether or when a token is issued.
  • Farm steps name a cost and a duration for each action. Nothing here is financial advice; check the protocol’s own pages before moving funds.
